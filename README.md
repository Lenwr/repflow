# Repflow

MVP responsive pour gérer et exécuter des programmes de musculation, seul ou avec un coach.

## Lancer localement

```bash
npm install
npm run dev
```

Sans variables d’environnement, l’application fonctionne en mode démonstration. Firebase est utilisé pour l’authentification. Les données métier sont encore migrées progressivement depuis Supabase ; les règles Firestore se trouvent dans `firestore.rules`.

## Parcours inclus

- pratiquant autonome ;
- pratiquant accompagné par un coach ;
- tableau de bord coach ;
- séance interactive et validation des séries ;
- progression, clients et programmes ;
- modèle relationnel Supabase prêt à être complété.
